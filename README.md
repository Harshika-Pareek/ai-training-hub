## How to use these notebooks
**In your browser (recommended):** click **Open in Colab**, then *File → Save a copy in Drive*. No installation needed.

**On your own machine:**
```bash
git clone https://github.com/Harshika-Pareek/ai-training-hub.git
cd ai-training-hub
pip install -r requirements.txt
```
Then open the notebook in VS Code or Jupyter.

Some steps optionally use a free Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey). Store it as a Colab secret or an environment variable named `GEMINI_API_KEY`. Never commit keys to a repository.
